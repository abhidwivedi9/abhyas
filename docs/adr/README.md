## Writing a new ADR

Copy the structure of an existing ADR: **Context** (the forces at play),
**Decision** (what we're doing, concretely), **Consequences** (good and bad —
an ADR with no downsides listed is unfinished). Number sequentially, one
decision per ADR, and supersede rather than edit accepted ADRs.
